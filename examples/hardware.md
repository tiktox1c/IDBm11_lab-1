# Аппаратные и программные средства локального ИИ

Этот материал объясняет назначение основных компонентов компьютера и порядок работы локальной системы ИИ. Рассматривается упрощённая система, в которой вычисления выполняет центральный процессор.

## Память и вычисления

Центральный процессор — компонент, который выполняет инструкции программы и арифметические операции.
Оперативная память — компонент, который временно хранит используемые программой данные во время работы.
Твердотельный накопитель — компонент, который хранит файлы после выключения питания.

Оперативная память энергозависима. Сохранённые на накопителе файлы модели не исчезают после выключения компьютера.

В рассматриваемой системе запуск сохранённой модели выполняется в следующем порядке.
1. Прочитать файл модели с накопителя.
2. Разместить параметры модели в оперативной памяти.
3. Выполнить вычисления центральным процессором.
Переход к следующему шагу выполняется после завершения предыдущего. Эта последовательность описывает выбранный учебный пример, а не все способы исполнения моделей.

## Программы для выполнения модели

Интерпретатор Python — программа, которая выполняет код приложения на языке Python.
Драйвер устройства — программа, которая обеспечивает взаимодействие операционной системы с устройством.
Планировщик операционной системы — компонент, который распределяет процессорное время между выполняемыми задачами.

Виртуальное окружение Python хранит отдельный набор библиотек проекта. Оно помогает разделять зависимости разных приложений. Создание виртуального окружения не устанавливает сам интерпретатор Python.

В учебном приложении обработка входного документа выполняется в следующем порядке.
1. Прочитать доступный текст документа.
2. Выбрать содержательный фрагмент извлечённого текста.
3. Передать выбранный фрагмент локальной языковой модели.
Выбор фрагмента требует предварительного получения текста. Модель получает подготовленный фрагмент после выбора.

## Обмен данными в локальном приложении

Локальный API — интерфейс, через который программы на одном компьютере обмениваются запросами и ответами.
JSON — текстовый формат представления структурированных данных.
Тайм-аут — предельное время ожидания операции, после которого приложение сообщает об отсутствии результата.

Локальное выполнение модели не требует передачи учебного документа облачному сервису. Ответ в формате JSON всё равно нуждается в проверке обязательных полей и содержания.

В данном приложении подготовка результата модели выполняется в следующем порядке.
1. Получить ответ локальной модели.
2. Проверить структуру и связь ответа с исходным фрагментом.
3. Показать прошедшие проверки задания преподавателю.
Показ задания следует после автоматической проверки. Преподаватель оценивает смысловую правильность перед использованием теста.
