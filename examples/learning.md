# Основы машинного обучения и подготовки данных

Материал знакомит с данными, задачами машинного обучения и разделением обучения и проверки. Описанные процедуры являются учебными примерами с заранее установленным порядком действий.

## Данные для обучения с учителем

Признак — измеряемая характеристика объекта, которую используют при построении прогноза.
Метка — известное целевое значение для примера в обучении с учителем.
Обучающая выборка — набор примеров, на котором подбирают параметры модели.

При классификации метка обозначает класс объекта. Например, в задаче различения изображений кошек и собак меткой служит название соответствующего класса. Тестовая выборка используется для оценки уже обученной модели.

В рассматриваемом учебном эксперименте работа выполняется в следующем порядке.
1. Разделить подготовленные примеры на обучающую и тестовую выборки.
2. Обучить модель только на обучающей выборке.
3. Оценить обученную модель на тестовой выборке.
Тестовые примеры не используются для подбора параметров во втором шаге. Оценка следует после завершения обучения.

## Основные задачи анализа данных

Классификация — задача определения класса объекта.
Регрессия — задача прогнозирования числового значения.
Кластеризация — задача объединения похожих объектов в группы без заранее заданных меток классов.

Различение кошки и собаки на изображении является примером классификации. Прогноз цены квартиры является примером регрессии. Объединение покупателей в группы по сходству поведения является примером кластеризации.

В учебной программе применение готового классификатора выполняется в следующем порядке.
1. Получить признаки нового объекта.
2. Передать признаки обученному классификатору.
3. Получить предсказанный класс объекта.
Классификатор получает признаки после их подготовки. Результатом описанной процедуры является класс, а не новое обучение модели.

## Упрощённый искусственный нейрон

Вес — числовой параметр, который задаёт вклад входного признака в вычисление нейрона.
Взвешенная сумма — сумма произведений входных значений на соответствующие веса.
Функция активации — функция, которая преобразует взвешенную сумму в выход нейрона.

В этом учебном примере рассматривается нейрон без отдельного параметра смещения. Обучение изменяет параметры модели, а применение уже обученной модели использует сохранённые параметры.

Вычисление выхода рассматриваемого нейрона выполняется в следующем порядке.
1. Умножить каждое входное значение на соответствующий вес.
2. Сложить полученные произведения.
3. Применить функцию активации к полученной сумме.
Сложение выполняется после умножения, а применение функции активации — после получения суммы. Такая процедура относится к описанной упрощённой модели нейрона.
