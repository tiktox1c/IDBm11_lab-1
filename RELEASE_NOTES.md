# Публикация учебного проекта

Добавлены инструкция преподавателю, авторские PDF/DOCX для проверки четырёх типов заданий и скриншоты интерфейса в README. Полный установщик распространяется ZIP-архивом через GitHub Releases. Исходный Git-репозиторий не содержит весов и пользовательских материалов.

GUI-тесты теперь дожидаются готовности стартового подключения перед редактированием; случайное выполнение теста при busy=true больше не подменяет проверку черновика. Основной код программы и модель не менялись.

# Исправление установщика 1.0.1 — 23 октября 2026

- Исправлено падение при обычном выборе папки без параметра MODELSDIR: несуществующая константа Inno Setup userprofile заменена безопасным чтением USERPROFILE. Для поиска Ollama аналогично читается LOCALAPPDATA: отсутствие системной папки не прерывает мастер. Окружение Windows не изменяется.
- На странице выбора папки указан размер всего нового комплекта (программа, Ollama, Qwen), а не только приложения. Перед установкой показана сумма новых файлов с учётом повторного использования.
- Добавлены проверки ветки с отсутствующей Ollama/моделью и расчёта места при разных сочетаниях повторного использования. Основное приложение и модель не менялись.

# Релиз-кандидат — 22 октября 2026

Модель: qwen2.5:1.5b через локальную Ollama. Три вкладки, три явных ручных статуса, единственная кнопка экспорта Word. Добавлены структурированные элементы документа и вложения таблиц, рисунков и формул. Текстовая модель не распознаёт пиксели.

Проверки текущих исходников: 138 автоматических тестов (проверки сценария Inno Setup пропускаются, если локальный компилятор не размещён); запуск run.bat; реальная генерация по двум PDF и DOCX, отдельный реальный вопрос по формуле; DOC и открытие экспортов через установленный Word. Восемь вопросов не гарантируются: в итоговых прогонах получено 7/8, 6/8 и 4/8. Требуется ручная смысловая проверка. Скриншоты в README используют подготовленный материал без личных путей.

Создана Windows x64 onedir-сборка PyInstaller 6.22.3. Файл AI Test Generator.exe запускается из собранной папки и закрывается с кодом 0. PDF/DOCX/DOC, настоящее вычисление Qwen2.5 1.5B (7/8 вопросов всех четырёх типов), редактор, вложения и Word-экспорт проверены отдельным замороженным проверочным запуском с побайтово одинаковыми 15 модулями приложения. Проверочный запуск не включён в поставку. Совпадающие исходники предоставляются отдельным архивом Release.

Дополнительно создан автономный `AI-Test-Generator-Setup.exe`: приложение, Ollama 0.40.7 для CPU и qwen2.5:1.5b (около 1 ГБ весов). Установщик Inno Setup 6.7.3 позволяет выбрать папки; пути хранятся в installation.ini, переменные Windows и PATH не меняются. В облегчённый ZIP Ollama и модель не включены. Microsoft Word нужен только для DOC.

Проверены реальная установка в путь с кириллицей и пробелами, контрольные суммы всех 7 файлов модели, повторная установка без изменения времени записи весов, удаление с сохранением модели/Ollama/пользовательского файла, отказ при неполной Ollama и попытке установки поверх исходников. Установленная EXE создаёт настоящее окно Tkinter без Python в PATH и закрывается с кодом 0. Комплектный CPU-runner запускается; существующий локальный сервер повторно используется. Исправлено ложное распознавание rootfs-конфига как вложенного манифеста и принятие одного ollama.exe за полную установку.

Проверка на чистом компьютере и отдельный холодный запуск комплектного сервера при полностью отсутствующей Ollama не проводились. Работающий сервер пользователя для тестирования не останавливался. Автоматический запуск с выбранным хранилищем, отсутствие второго сервера и конфликты путей дополнительно проверены автоматическими тестами. Сборка не подписана цифровой подписью. Подробности пользовательских шагов — в README.
